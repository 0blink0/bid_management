<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client -> `/knowledge/query` API | 外部输入的 query/limit/type 进入后端检索链路 |
| API -> vector db/embedding | 服务端向下游依赖发起查询，存在可用性与错误泄漏风险 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | T | `knowledge.py` request parsing | mitigate | 使用 Pydantic 约束字段并在入口执行 limit 上限截断，非法请求返回 422 |
| T-02-02 | I | `knowledge.py` error response | mitigate | 统一错误体，避免原始异常堆栈直出，仅暴露 `error_code/message/details/request_id` |
| T-02-03 | D | qdrant/embedding dependency | mitigate | 下游异常映射 503 + `retryable=true`，让调用方快速重试或降级 |
</threat_model>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client -> `/knowledge/ingest/rebuild` | 外部请求触发高成本重建操作 |
| task worker -> ingest pipeline | 异步执行跨越加载/向量/写库链路，存在失败与一致性风险 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-04 | D | `POST /knowledge/ingest/rebuild` | mitigate | 使用异步任务模型立即返回 task_id，避免请求长时间阻塞 |
| T-02-05 | R | `tasks.py` 状态跟踪 | mitigate | 对每个 task 记录 request_id、状态流转和时间戳，保证可追踪 |
| T-02-06 | I | task error payload | mitigate | 对外仅暴露标准错误字段，不透传原始堆栈与敏感配置 |
</threat_model>

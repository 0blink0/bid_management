## 1. 项目概述

### 1.1 项目背景

随着我国公共资源交易市场化改革不断深化，招投标领域面临着日益严峻的合规监管挑战，包括串标围标、虚假资质、关联公司围标等问题。传统人工审查方式效率低、覆盖面窄、标准不统一。

### 1.2 建设目标

通过AI Agent技术实现招投标文件的智能审查，提高工作效率，减少人工疏漏，为决策提供全面参考意见。

### 1.3 建设原则

- **API-first**：核心服务通过API暴露，支持多种客户端和外部系统集成
- **Agent架构**：基于LangGraph实现多Agent协作，支持功能灵活扩展
- **四层记忆机制**：每个Agent具有独立的四层记忆能力
- **安全可控**：确保系统和数据安全，支持私有化部署
- **循序渐进**：分阶段建设，逐步完善
- **人机协同**：系统输出仅作为辅助参考，不替代法定责任主体

### 2.2 架构特性

1. **前后端分离**：Vue3前端通过REST API与后端通信
2. **多Agent协作**：基于LangGraph实现复杂的Agent工作流
3. **四层记忆机制**：每个Agent具有独立的记忆能力
4. **LLM可扩展**：支持前期阿里云API、后期私有化部署
5. **模型无关性**：通过LLM Router实现模型路由，Agent业务逻辑与底层模型解耦
6. **统一文档解析**：基于Unstructured.io的文档处理
7. **多数据库协同**：PostgreSQL + Qdrant + Neo4j + Redis

### 5.2 Agent职责边界

#### Coordinator Agent（协调器）
| 维度 | 内容 |
|------|------|
| **核心职责** | 意图识别、任务分解、调度汇总 |
| **输入边界** | 用户原始请求（文本描述或文件ID列表） |
| **不做什么** | 不直接处理文档、不做合规检查、不做比对 |
| **调用关系** | 被前端API调用 → 调用 Parser/Compliance/Comparison 等 → 汇总结果 |
| **输出目的地** | 返回给前端API，或传递给下游Agent |

#### Parser Agent（文档解析）
| 维度 | 内容 |
|------|------|
| **核心职责** | PDF解析、OCR识别、文本提取、表格提取 |
| **输入边界** | 文件ID（从Coordinator或前端来） |
| **不做什么** | 不做内容审查、不做格式校验、不做语义分析 |
| **调用关系** | 被Coordinator调用 → 从存储读取文件 → 返回结构化内容 |
| **输出目的地** | 返回给Coordinator，再传递给Compliance/Comparison等 |

#### Compliance Agent（合规审查）
| 维度 | 内容 |
|------|------|
| **核心职责** | 错敏词检测、合规性检查、条款完整性、评标办法检查 |
| **输入边界** | Parser输出的DocumentContent + 知识库规则 |
| **不做什么** | 不做资质核验（Qualification）、不做相似度分析（Risk） |
| **调用关系** | 被Coordinator调用 → 读取知识库规则 → 返回问题列表 |
| **输出目的地** | 返回给Coordinator汇总，或直接给Archive |

#### Comparison Agent（比对分析）
| 维度 | 内容 |
|------|------|
| **核心职责** | 招投标响应性比对、要求-响应映射、未响应/弱响应识别 |
| **输入边界** | 招标文件解析结果 + 投标文件解析结果 |
| **不做什么** | 不做资质核验（Qualification）、不做风险识别（Risk） |
| **与Risk区分** | Comparison专注"响应是否匹配"，Risk专注"围串标检测" |
| **调用关系** | 被Coordinator调用 → 需两个文件解析结果 → 返回比对结果 |

#### Qualification Agent（资质核验）
| 维度 | 内容 |
|------|------|
| **核心职责** | 企业/人员/证书提取、有效期核验、单位一致性检查 |
| **输入边界** | 投标文件解析结果 + 资质标准要求 |
| **不做什么** | 不做响应性比对（Comparison）、不做风险检测（Risk） |
| **与Comparison区分** | Comparison比对"响应内容"，Qualification核验"资质有效性" |
| **调用关系** | 被Coordinator调用 → 读取资质标准库 → 返回核验结果 |

#### Risk Agent（风险识别）
| 维度 | 内容 |
|------|------|
| **核心职责** | 围串标检测、相似度分析、联系方式重合、报价离散度、关联企业 |
| **输入边界** | 多个投标文件解析结果（通常至少2个） |
| **不做什么** | 不做响应性比对（Comparison）、不做资质核验（Qualification） |
| **与Comparison区分** | Risk专注"多文件间异常"，Comparison专注"单文件响应匹配" |
| **调用关系** | 被Coordinator调用 → 需多个文件 → 返回风险列表 |

#### Evaluation Agent（辅助评标）
| 维度 | 内容 |
|------|------|
| **核心职责** | 评分标准配置、客观项分析、评分建议 |
| **输入边界** | 招标文件（含评标办法）+ 投标文件 |
| **不做什么** | 不做主观评分、不做资格后审 |
| **调用关系** | 被Coordinator调用 → 需要评标办法 + 投标文件 → 返回评分建议 |

#### Expert Agent（专家抽取）
| 维度 | 内容 |
|------|------|
| **核心职责** | 专家库管理、随机抽取、回避过滤 |
| **输入边界** | 抽取条件（专业、数量）+ 回避条件 |
| **不做什么** | 不做资格核验、不做评标 |
| **调用关系** | 被Coordinator调用 → 读取专家库 → 返回抽取结果 |

#### Archive Agent（档案管理）
| 维度 | 内容 |
|------|------|
| **核心职责** | 任务跟踪、整改记录、报告归档 |
| **输入边界** | 任务ID + 归档内容 |
| **不做什么** | 不做审查、不做分析 |
| **调用关系** | 被Coordinator或前端调用 → 存储归档数据 → 返回归档确认 |

#### Statistics Agent（统计分析）
| 维度 | 内容 |
|------|------|
| **核心职责** | 风险总览、问题统计、整改分析、报表导出 |
| **输入边界** | 时间范围、筛选条件 |
| **不做什么** | 不做单文件审查、不做实时监控 |
| **调用关系** | 被前端调用 → 聚合历史数据 → 返回统计报表 |

### 5.3 Agent基类

```python
# app/agents/base/agent.py

from abc import ABC, abstractmethod
from typing import Any, Dict, Optional, Type
from pydantic import BaseModel
from langgraph.graph import StateGraph
from .memory import AgentMemory
from .executor import AgentExecutor
from .schemas.base import BaseAgentInput, BaseAgentOutput

class BaseAgent(ABC):
    """
    Agent抽象基类
    所有Agent继承此类
    """

    def __init__(
        self,
        agent_id: str,
        name: str,
        input_schema: Type[BaseAgentInput],
        output_schema: Type[BaseAgentOutput],
        system_prompt_template: str,
        llm_config: Dict[str, Any] = None
    ):
        self.agent_id = agent_id
        self.name = name
        self.input_schema = input_schema
        self.output_schema = output_schema
        self.system_prompt = system_prompt_template
        self.memory = AgentMemory(agent_id)
        self.graph = self._build_graph()
        self.llm_config = llm_config or self._default_llm_config()

        # 创建执行器（含校验+重试）
        self.executor = AgentExecutor(
            agent_id=agent_id,
            input_schema=input_schema,
            output_schema=output_schema,
            system_prompt_template=system_prompt_template,
            llm_config=self.llm_config
        )

    @abstractmethod
    def _build_graph(self) -> StateGraph:
        """构建LangGraph"""
        pass

    @abstractmethod
    async def process(self, input_data: BaseAgentInput) -> BaseAgentOutput:
        """处理输入"""
        pass

    def _default_llm_config(self) -> Dict[str, Any]:
        """默认LLM配置"""
        return {
            "temperature": 0.1,
            "max_tokens": 4096,
            "response_format": {"type": "json_object"}
        }

    def get_memory(self) -> AgentMemory:
        return self.memory
```

    workflow = StateGraph(CoordinatorState)

    # 添加节点
    workflow.add_node("intent_recognition", intent_recognition_node)
    workflow.add_node("task_decomposition", task_decomposition_node)
    workflow.add_node("agent_dispatch", agent_dispatch_node)

        return "continue"

    workflow.add_edge("task_decomposition", "agent_dispatch")
    workflow.add_edge("agent_dispatch", "result_aggregation")

### 6.3 分层校验器实现

```python
# app/agents/validators/layered.py

from abc import ABC, abstractmethod
from typing import Type, Generic, TypeVar, Tuple, List, Any
from pydantic import BaseModel, ValidationError as PydanticValidationError
from .parsers import JsonParser, MarkdownCodeBlockParser
from .schema_validator import PydanticSchemaValidator
from .business_validator import (
    LogicalConsistencyValidator,
    EnumRangeValidator,
    NumericRangeValidator
)


class ContentParser(ABC):
    """内容解析器抽象类"""
    @abstractmethod
    def parse(self, raw_output: str) -> dict:
        pass


class LayeredValidator:
    """
    分层校验器
    按顺序执行：JSON解析 → Schema校验 → 业务校验
    """

    def __init__(self):
        self.parsers: List[ContentParser] = [
            JsonParser(),
            MarkdownCodeBlockParser(),
        ]
        self.schema_validator = PydanticSchemaValidator()
        self.business_validators = [
            LogicalConsistencyValidator(),
            EnumRangeValidator(),
            NumericRangeValidator(),
        ]

    def validate(
        self,
        raw_output: str,
        schema: Type[BaseModel]
    ) -> Tuple[Optional[dict], List[ValidationError]]:
        """
        执行分层校验
        返回: (校验通过的结果, 错误列表)
        """
        errors: List[ValidationError] = []
        parsed_data = None

        # Layer 1: JSON解析
        for parser in self.parsers:
            try:
                parsed_data = parser.parse(raw_output)
                break
            except Exception as e:
                continue

        if parsed_data is None:
            errors.append(ValidationError(
                error_type=AgentError.JSON_PARSE_ERROR,
                message=f"All parsers failed: {str(e)}",
                field_path="root",
                llm_output_snippet=raw_output[:500] if raw_output else ""
            ))
            return None, errors

        # Layer 2: Schema校验
        validated_data, schema_errors = self.schema_validator.validate(
            parsed_data, schema
        )
        errors.extend(schema_errors)

        if validated_data is None:
            return None, errors

        # Layer 3: 业务校验
        for validator in self.business_validators:
            _, biz_errors = validator.validate(validated_data, schema)
            errors.extend(biz_errors)

        if errors:
            return None, errors

        return validated_data, []
```

### 6.4 JSON解析器实现

```python
# app/agents/validators/parsers.py

import json
import re
from abc import ABC, abstractmethod
from typing import Optional


class ContentParser(ABC):
    """内容解析器抽象类"""
    @abstractmethod
    def parse(self, raw_output: str) -> dict:
        pass


class JsonParser(ContentParser):
    """标准JSON解析器"""

    def parse(self, raw_output: str) -> dict:
        cleaned = raw_output.strip()
        # 移除不可见字符
        cleaned = cleaned.replace('\x00', '').replace('\x01', '')
        return json.loads(cleaned)


class MarkdownCodeBlockParser(ContentParser):
    """Markdown代码块解析器（处理 ```json ... ``` 格式）"""

    JSON_BLOCK_PATTERN = re.compile(
        r'```(?:json)?\s*\n?(.*?)\n?```',
        re.DOTALL
    )

    def parse(self, raw_output: str) -> dict:
        match = self.JSON_BLOCK_PATTERN.search(raw_output)
        if match:
            json_str = match.group(1).strip()
            return json.loads(json_str)

        # 没有代码块，尝试直接解析
        return json.loads(raw_output.strip())


class IncompleteJsonFixer:
    """不完整JSON修复器（用于处理LLM输出被截断的情况）"""

    TRUNCATION_INDICATORS = [
        '"content": "...',
        '"description": "...',
        '...\n',
        '"...',
    ]

    def try_fix(self, raw_output: str) -> Optional[str]:
        """尝试修复不完整的JSON"""
        if any(ind in raw_output for ind in self.TRUNCATION_INDICATORS):
            return self._auto_complete_json(raw_output)
        return None

    def _auto_complete_json(self, json_str: str) -> str:
        """自动补全JSON（简化版本）"""
        lines = json_str.split('\n')
        completed_lines = []
        brace_count = 0
        in_string = False
        escape_next = False

        for line in lines:
            for char in line:
                if escape_next:
                    escape_next = False
                    continue
                if char == '\\':
                    escape_next = True
                    continue
                if char == '"' and not escape_next:
                    in_string = not in_string
                if not in_string:
                    if char == '{':
                        brace_count += 1
                    elif char == '}':
                        brace_count -= 1

            completed_lines.append(line)

            # 如果到达平衡状态且不是在一段字符串中间，可能是完整语句
            if brace_count == 0 and in_string:
                # 可能在字符串中间，继续等待
                pass

        return '\n'.join(completed_lines)
```

        schema: Type[BaseModel]

                field_path = '.'.join(str(loc) for loc in error['loc'])

```python
# app/agents/validators/business_validator.py

from typing import Type, Tuple, Optional, List, Any, Dict
from pydantic import BaseModel, Field
from pydantic.fields import FieldInfo
from enum import Enum
from app.agents.exceptions import ValidationError, AgentError


class LogicalConsistencyValidator:
    """逻辑一致性校验器"""

    def validate(
        self,
        data: dict,
        schema: Type[BaseModel]
    ) -> Tuple[Optional[dict], List[ValidationError]]:
        errors = []

        # 规则1: overall_status是pass时，issues应为空或无严重问题
        if 'overall_status' in data and 'issues' in data:
            if data['overall_status'] == 'pass' and data['issues']:
                critical_issues = [
                    i for i in data['issues']
                    if isinstance(i, dict) and i.get('severity') == 'critical'
                ]
                if critical_issues:
                    errors.append(ValidationError(
                        error_type=AgentError.LOGICAL_INCONSISTENCY,
                        message="Status is 'pass' but critical issues found",
                        field_path="overall_status"
                    ))

        # 规则2: 分数必须在0-100范围
        score_fields = ['score', 'risk_score', 'overall_match_rate', 'total_score']
        for field_name in score_fields:
            if field_name in data and data[field_name] is not None:
                score = data[field_name]
                if not isinstance(score, (int, float)):
                    errors.append(ValidationError(
                        error_type=AgentError.BUSINESS_LOGIC_ERROR,
                        message=f"{field_name} must be numeric",
                        field_path=field_name,
                        raw_value=score
                    ))
                elif not 0 <= score <= 100:
                    errors.append(ValidationError(
                        error_type=AgentError.BUSINESS_LOGIC_ERROR,
                        message=f"{field_name} must be between 0-100",
                        field_path=field_name,
                        raw_value=score
                    ))

        return data if not errors else None, errors


class EnumRangeValidator:
    """枚举值范围校验器"""

    def validate(
        self,
        data: dict,
        schema: Type[BaseModel]
    ) -> Tuple[Optional[dict], List[ValidationError]]:
        errors = []

        # 获取schema中定义的枚举字段
        enum_fields = self._extract_enum_fields(schema)

        for field_path, enum_class in enum_fields.items():
            value = self._get_nested_value(data, field_path)
            if value is not None:
                valid_values = [e.value for e in enum_class]
                if isinstance(enum_class, type) and issubclass(enum_class, Enum):
                    if value not in valid_values:
                        errors.append(ValidationError(
                            error_type=AgentError.ENUM_VALUE_ERROR,
                            message=f"Invalid enum value '{value}'. Expected one of {valid_values}",
                            field_path=field_path,
                            raw_value=value,
                            expected=valid_values
                        ))

        return data if not errors else None, errors

    def _extract_enum_fields(self, schema: Type[BaseModel]) -> Dict[str, Type[Enum]]:
        """提取schema中的枚举字段"""
        result = {}
        if hasattr(schema, 'model_fields'):
            for field_name, field_info in schema.model_fields.items():
                if hasattr(field_info, 'annotation'):
                    annotation = field_info.annotation
                    if hasattr(annotation, '__origin__'):
                        # 处理 Optional[Enum] 情况
                        origin = getattr(annotation, '__origin__', None)
                        if origin is not None:
                            args = getattr(annotation, '__args__', [])
                            for arg in args:
                                if isinstance(arg, type) and issubclass(arg, Enum):
                                    result[field_name] = arg
                    elif isinstance(annotation, type) and issubclass(annotation, Enum):
                        result[field_name] = annotation
        return result

    def _get_nested_value(self, data: dict, field_path: str) -> Any:
        """获取嵌套字段值"""
        keys = field_path.split('.')
        value = data
        for key in keys:
            if isinstance(value, dict):
                value = value.get(key)
            else:
                return None
        return value


class NumericRangeValidator:
    """数值范围校验器"""

    def validate(
        self,
        data: dict,
        schema: Type[BaseModel]
    ) -> Tuple[Optional[dict], List[ValidationError]]:
        errors = []

        # 检查常见的数值字段范围
        range_constraints = {
            'total_issues': (0, None),  # >= 0
            'critical_count': (0, None),
            'high_count': (0, None),
            'medium_count': (0, None),
            'low_count': (0, None),
            'total_pages': (1, None),  # >= 1
        }

        for field_name, (min_val, max_val) in range_constraints.items():
            if field_name in data and data[field_name] is not None:
                value = data[field_name]
                if not isinstance(value, (int, float)):
                    continue
                if min_val is not None and value < min_val:
                    errors.append(ValidationError(
                        error_type=AgentError.BUSINESS_LOGIC_ERROR,
                        message=f"{field_name} must be >= {min_val}",
                        field_path=field_name,
                        raw_value=value
                    ))
                if max_val is not None and value > max_val:
                    errors.append(ValidationError(
                        error_type=AgentError.BUSINESS_LOGIC_ERROR,
                        message=f"{field_name} must be <= {max_val}",
                        field_path=field_name,
                        raw_value=value
                    ))

        return data if not errors else None, errors
```

### 6.7 重试策略实现

```python
# app/agents/retry.py

import random
import asyncio
from dataclasses import dataclass, field
from typing import List
from datetime import datetime


@dataclass
class RetryConfig:
    """重试配置"""
    max_attempts: int = 3
    initial_delay: float = 1.0
    max_delay: float = 10.0
    exponential_base: float = 2.0

    retry_on_parse_error: bool = True
    retry_on_schema_error: bool = True
    retry_on_business_error: bool = True
    retry_on_llm_api_error: bool = True
    retry_on_timeout: bool = True

    never_retry_on: List[AgentError] = field(default_factory=list)


class RetryStrategy:
    """重试策略"""

    def __init__(self, config: RetryConfig = None):
        self.config = config or RetryConfig()

    def should_retry(self, errors: List[ValidationError], context: RetryContext) -> bool:
        """判断是否应该重试"""
        # 达到最大次数，不重试
        if context.attempt >= self.config.max_attempts:
            return False

        # 检查是否有不该重试的错误
        for error in errors:
            if error.error_type in self.config.never_retry_on:
                return False

        # 根据错误类型判断
        parse_errors = [e for e in errors if e.error_type == AgentError.JSON_PARSE_ERROR]
        schema_errors = [e for e in errors if e.error_type == AgentError.SCHEMA_VALIDATION_ERROR]
        business_errors = [e for e in errors if e.error_type == AgentError.BUSINESS_LOGIC_ERROR]

        if parse_errors and not self.config.retry_on_parse_error:
            return False
        if schema_errors and not self.config.retry_on_schema_error:
            return False
        if business_errors and not self.config.retry_on_business_error:
            return False

        return True

    def get_retry_delay(self, attempt: int) -> float:
        """计算重试延迟（指数退避+抖动）"""
        delay = min(
            self.config.initial_delay * (self.config.exponential_base ** (attempt - 1)),
            self.config.max_delay
        )
        # 添加随机抖动 (±20%)
        jitter = delay * 0.2 * (2 * random.random() - 1)
        return max(0, delay + jitter)

    def get_error_summary(self, errors: List[ValidationError]) -> str:
        """生成错误摘要"""
        summaries = []
        for error in errors:
            summaries.append(f"[{error.error_type.value}] {error.field_path}: {error.message}")
        return "; ".join(summaries)
```

### 6.8 Agent执行器整合

```python
# app/agents/executor.py

import asyncio
import json
from typing import Type, Any, Optional
from datetime import datetime
from pydantic import BaseModel

from app.agents.exceptions import (
    ValidationError, RetryContext, ExecutionResult, AgentError
)
from app.agents.validators.layered import LayeredValidator
from app.agents.retry import RetryStrategy, RetryConfig
from app.tools.llm.manager import LLMManager


class AgentExecutor:
    """
    Agent执行器
    整合LLM调用、校验、重试
    """

    def __init__(
        self,
        agent_id: str,
        input_schema: Type[BaseAgentInput],
        output_schema: Type[BaseAgentOutput],
        system_prompt_template: str,
        llm_config: Dict[str, Any] = None
    ):
        self.agent_id = agent_id
        self.input_schema = input_schema
        self.output_schema = output_schema
        self.system_prompt = system_prompt_template
        self.llm_config = llm_config or {}

        self.llm_manager = LLMManager()
        self.validator = LayeredValidator()
        self.retry_strategy = RetryStrategy()

    async def execute(
        self,
        input_data: BaseAgentInput,
        thread_id: str = None
    ) -> ExecutionResult:
        """执行Agent处理"""
        start_time = datetime.now()
        context = RetryContext(
            attempt=0,
            max_attempts=self.retry_strategy.config.max_attempts,
            original_input=input_data,
            start_time=start_time
        )

        last_error: ValidationError = None

        while context.attempt < context.max_attempts:
            context.attempt += 1

            try:
                # 构建Prompt
                prompt = self._build_prompt(input_data, context, last_error)

                # 调用LLM
                raw_output = await self.llm_manager.chat(
                    messages=[
                        {"role": "system", "content": self.system_prompt},
                        {"role": "user", "content": prompt}
                    ],
                    temperature=self.llm_config.get('temperature', 0.1),
                    response_format={"type": "json_object"}
                )

                # 校验输出
                validated_result, errors = self.validator.validate(
                    raw_output,
                    self.output_schema
                )

                if validated_result is not None:
                    processing_time = int(
                        (datetime.now() - start_time).total_seconds() * 1000
                    )
                    return ExecutionResult(
                        success=True,
                        data=validated_result,
                        attempt=context.attempt,
                        errors=[],
                        processing_time_ms=processing_time
                    )

                # 校验失败
                context.errors.extend(errors)
                last_error = errors[0] if errors else None

                if not self.retry_strategy.should_retry(errors, context):
                    break

                # 计算延迟
                delay = self.retry_strategy.get_retry_delay(context.attempt)
                await asyncio.sleep(delay)

            except asyncio.TimeoutError:
                last_error = ValidationError(
                    error_type=AgentError.LLM_TIMEOUT,
                    message="LLM API timeout",
                    field_path="root"
                )
                context.errors.append(last_error)

            except Exception as e:
                last_error = ValidationError(
                    error_type=AgentError.LLM_API_ERROR,
                    message=str(e),
                    field_path="root"
                )
                context.errors.append(last_error)

        # 所有重试都失败
        processing_time = int((datetime.now() - start_time).total_seconds() * 1000)
        return ExecutionResult(
            success=False,
            data=None,
            attempt=context.attempt,
            errors=context.errors,
            error_summary=self.retry_strategy.get_error_summary(context.errors),
            processing_time_ms=processing_time
        )

    def _build_prompt(
        self,
        input_data: BaseAgentInput,
        context: RetryContext,
        last_error: Optional[ValidationError]
    ) -> str:
        """构建Prompt"""
        prompt_parts = []

        # 输入数据
        if isinstance(input_data, BaseModel):
            input_json = input_data.model_dump_json(indent=2)
        else:
            input_json = json.dumps(input_data, ensure_ascii=False, indent=2)

        prompt_parts.append(f"## 输入数据\n```json\n{input_json}\n```")

        # 上一次错误（用于引导LLM修正）
        if last_error and context.attempt > 1:
            prompt_parts.append(f"""
## 上一次输出的错误（请修正）
```
错误类型: {last_error.error_type.value}
错误位置: {last_error.field_path}
错误描述: {last_error.message}
原始值: {last_error.raw_value}
```
""")

        # 输出格式要求
        prompt_parts.append(f"""
## 输出格式要求
必须输出符合以下Schema的JSON，不要包含任何其他内容：
```json
{self.output_schema.model_json_schema()}
```
""")

        return "\n".join(prompt_parts)
```

class FallbackStrategy:

            "comparison": FallbackStrategy._comparison_fallback,

            "risk": FallbackStrategy._risk_fallback,
        }

        fallback_func = fallback_map.get(agent_type, FallbackStrategy._default_fallback)
        return fallback_func(original_request, errors, output_schema)

    def _compliance_fallback(
        request: Any,
        errors: List[ValidationError],
        schema: Type[BaseModel]
    ) -> BaseModel:
        """合规审查降级结果"""
        from app.agents.exceptions import AgentError

        for error in errors:

            task_id=request.task_id,

            overall_status="warning",
            score=50,
            issues=[],
            summary={"total_issues": 0, "check_time_ms": 0},

            status="failed",

            file_id=getattr(request, 'file_id', ''),

            entities=[],
            validation_details=[],
            status="failed",
            error_message="资质核验失败，请人工处理"
        )

    @staticmethod

            overall_risk_level="undetermined",
            risk_score=0,
            risks=[],
            correlations=[],
            status="failed",
            error_message="风险识别失败，请人工处理"
        )

    @staticmethod
    def _default_fallback(
        request: Any,
        errors: List[ValidationError],
        schema: Type[BaseModel]
    ) -> BaseModel:
        """默认降级结果"""
        return schema(
            task_id=getattr(request, 'task_id', ''),
            status="failed",

        )

from typing import Optional, Dict, List, Any
from .base import BaseLLM
from .types import LLMConfig, LLMProvider

class LLMManager:
    """
    LLM管理器 - 统一管理LLM实例
    支持多实例、热切换、负载均衡
    """

    def __init__(self):
        self._instances: Dict[str, BaseLLM] = {}
        self._default: Optional[str] = None

    def add_llm(self, name: str, config: LLMConfig) -> None:
        """添加LLM实例"""
        instance = LLMRegistry.get(config)
        self._instances[name] = instance
        if self._default is None:
            self._default = name

    def set_default(self, name: str) -> None:
        """设置默认LLM"""
        self._default = name

    def get_llm(self, name: Optional[str] = None) -> BaseLLM:
        """获取LLM实例"""
        if name is None:
            name = self._default
        return self._instances[name]

    async def chat(
        self,
        messages: List[Dict[str, str]],
        temperature: float = 0.7,
        max_tokens: int = 4096,
        response_format: Optional[Dict[str, str]] = None,
        **kwargs
    ) -> str:
        """聊天"""
        return await self.get_llm().chat(
            messages,
            temperature=temperature,
            max_tokens=max_tokens,
            response_format=response_format,
            **kwargs
        )

    async def embeddings(self, texts: List[str]) -> List[List[float]]:
        """获取嵌入"""

from typing import Any, Optional
from datetime import datetime
import time

class ImmediateMemory:
    """
    瞬时记忆 - 原始输入 + LLM推理缓存
    生命周期: < 1分钟
    """

    def __init__(self, agent_id: str, ttl: int = 60):
        self.agent_id = agent_id
        self.ttl = ttl
        self._cache = {}

    def store(self, key: str, raw_input: str, llm_output: Optional[str] = None,
              sensory_data: Any = None) -> None:
        """存储瞬时记忆"""
        self._cache[key] = {
            "raw_input": raw_input,
            "llm_raw_output": llm_output,
            "sensory_cache": sensory_data,
            "timestamp": datetime.now(),
            "expires_at": time.time() + self.ttl
        }

    def get(self, key: str) -> Optional[dict]:
        """获取瞬时记忆"""
        if key in self._cache:
            entry = self._cache[key]
            if time.time() < entry["expires_at"]:
                return entry
            else:
                del self._cache[key]
        return None

    def cleanup(self) -> None:
        """清理过期记忆"""
        current_time = time.time()
        self._cache = {
            k: v for k, v in self._cache.items()
            if current_time < v["expires_at"]
        }

        self._agent_state.update(state)

    def clear_task(self, task_id: str) -> None:
        """清除任务记忆"""
        if task_id in self._task_context:
            del self._task_context[task_id]

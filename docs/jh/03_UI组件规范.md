# 智能招投标审查平台 - UI组件规范

---

## 1. 色彩系统

### 1.1 主色调

| 颜色 | 色值 | 用途 |
|:---|:---|:---|
| 主色深蓝 | `#1E5AA8` | Logo、重点标题、强调元素 |
| 主色蓝 | `#2C7BE5` | 主按钮、主链接、选中状态 |
| 主色浅蓝 | `#5A9FE8` | 悬停状态、次级强调 |

### 1.2 功能色

| 颜色 | 色值 | 用途 |
|:---|:---|:---|
| 成功绿 | `#38A169` | 通过状态、成功提示 |
| 警告黄 | `#ED8936` | 警告状态、临近过期 |
| 错误红 | `#E53E3E` | 错误状态、高风险 |
| 信息蓝 | `#3182CE` | 信息提示 |

### 1.3 中性色

| 颜色 | 色值 | 用途 |
|:---|:---|:---|
| 深灰 | `#1A202C` | 主标题文字 |
| 中灰 | `#4A5568` | 正文文字 |
| 浅灰 | `#718096` | 次级文字 |
| 边框灰 | `#E2E8F0` | 边框、分割线 |
| 背景灰 | `#F5F7FA` | 页面背景 |
| 卡片白 | `#FFFFFF` | 卡片背景 |

### 1.4 风险等级色

| 等级 | 背景色 | 文字色 | 含义 |
|:---|:---|:---|:---|
| 高风险 | `#FED7D7` | `#C53030` | 违规、严重问题 |
| 中风险 | `#FEEBC8` | `#C05621` | 异常、需关注 |
| 低风险 | `#C6F6D5` | `#276749` | 通过、正常 |
| 待处理 | `#EDF2F7` | `#4A5568` | 待审查 |

## 2. 字体系统

### 2.1 字体家族

```
中文：  "思源黑体", "Noto Sans SC", "Microsoft YaHei", sans-serif
英文/数字："Roboto", "Helvetica Neue", Arial, sans-serif
代码：    "JetBrains Mono", "Fira Code", Consolas, monospace
```

### 2.2 字体层级

| 层级 | 字号 | 字重 | 行高 | 用途 |
|:---|:---|:---|:---|:---|
| H1 | 28px | 700 | 1.3 | 页面大标题 |
| H2 | 22px | 600 | 1.3 | 模块标题 |
| H3 | 18px | 600 | 1.4 | 卡片标题 |
| H4 | 16px | 600 | 1.4 | 段落标题 |
| Body | 14px | 400 | 1.6 | 正文内容 |
| Caption | 12px | 400 | 1.5 | 辅助说明 |
| Small | 12px | 400 | 1.4 | 标签、小字 |

## 1. 设计概述

### 1.1 设计目标

- 提升业务人员操作效率，降低学习成本
- 结果展示直观、可解释、可追溯
- 符合政务/企业级B端产品审美标准

### 1.2 设计风格

| 特性 | 说明 |
|:---|:---|
| 风格定位 | 政务蓝 + 专业商务风 |
| 主色调 | #1E5AA8（政务蓝）、#2C7BE5（功能蓝） |
| 辅助色 | #F5F7FA（背景灰）、#FFFFFF（卡片白） |
| 警示色 | #E53E3E（高风险）、#ED8936（中等风险）、#38A169（通过） |
| 字体 | 思源黑体（中文）、Roboto（英文） |
| 圆角 | 6px（卡片）、4px（按钮）、2px（输入框） |
| 阴影 | 0 2px 8px rgba(0,0,0,0.08)（卡片） |

## 7. 权限设计

### 7.1 角色定义（前期简化）

| 角色 | 功能权限 |
|:---|:---|
| **管理员** | 用户管理、知识库管理、系统设置、操作日志查看 |
| **普通用户** | 文件审查、风险分析、辅助工具、档案管理、统计分析 |

### 7.2 权限矩阵

| 功能模块 | 普通用户 | 管理员 |
|:---|:---:|:---:|
| 首页/仪表盘 | ✅ | ✅ |
| 项目管理 | ✅ | ✅ |
| 文件审查（上传、检测、比对） | ✅ | ✅ |
| 风险分析（围串标、资质核验） | ✅ | ✅ |
| 辅助工具（评标、专家抽取） | ✅ | ✅ |
| 档案管理（任务、归档） | ✅ | ✅ |
| 统计分析 | ✅ | ✅ |
| 知识库管理 | ❌ | ✅ |
| 用户管理 | ❌ | ✅ |
| 系统设置 | ❌ | ✅ |
| 操作日志 | ❌ | ✅ |

### 7.3 权限扩展设计

为后续角色扩展预留以下设计：

```
权限体系架构
├── 功能权限 (Feature Permission)
│   ├── 角色定义 (Role Definition)
│   │   ├── 管理员 (Admin)
│   │   ├── 普通用户 (Normal User)
│   │   └── [预留] 审查员 (Reviewer)      ← 后期可扩展
│   │   └── [预留] 复核员 (Reviewer 2)    ← 后期可扩展
│   │   └── [预留] 查阅员 (Viewer)        ← 后期可扩展
│   └── 权限组 (Permission Group)
│       ├── 文件操作权限
│       ├── 审查操作权限
│       ├── 知识库权限
│       ├── 系统管理权限
│       └── [预留] 审计权限               ← 后期可扩展
│
├── 数据权限 (Data Permission)
│   ├── 全部数据
│   ├── 本部门数据                        ← 后期扩展
│   └── 本人数据
│
└── 字段权限 (Field Permission)           ← 后期扩展
    └── 敏感字段脱敏
```

### 7.4 权限扩展示例

后续如需新增角色，只需在角色管理中配置：

| 新增角色 | 继承基础 | 差异化权限 |
|:---|:---|:---|
| 审查员 | 普通用户 | + 审查任务分配权限 |
| 复核员 | 普通用户 | + 复查确认权限 |
| 审计员 | 管理员 | - 用户管理权限 + 审计日志查看 |

### 7.5 预留扩展点

| 扩展方向 | 预留设计 | 说明 |
|:---|:---|:---|
| 部门隔离 | 数据权限 | 预留 `department_id` 字段，支持按部门数据隔离 |
| 密级控制 | 字段权限 | 预留 `sensitivity_level` 字段，支持敏感信息脱敏 |
| 操作审计 | 审计日志 | 完整记录操作人、操作时间、操作内容、IP等 |
| 委托授权 | 代理权限 | 预留 `delegate_to` 字段，支持权限临时委托 |

## 8. 原型设计说明

本设计方案定义了：

1. **整体布局** - 顶部栏 + 左侧导航 + 主内容区
2. **导航结构** - 9个一级模块，涵盖所有业务功能
3. **8个核心页面** - 首页、文件上传、招标文件检测、响应比对、围串标检测、资质核验、档案管理、统计分析
4. **组件规范** - 按钮、表单、表格、卡片、状态标签
5. **交互流程** - 文件审查流程、围串标检测流程
6. **权限设计** - 角色定义和数据权限控制

后续可根据此设计文档进行UI设计和高保真原型制作。

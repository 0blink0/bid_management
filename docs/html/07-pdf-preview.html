3.1 投标人资格要求

3.1.1 投标人须具备以下条件：

  1. 具有独立承担民事责任的能力；
  2. 具有良好的商业信誉和健全的财务会计制度；
  3. 具有履行合同所必需的设备和专业技术能力；
  4. 具有信息系统集成一级资质 (应为二级)
    → 疑似过高，违反《招标投标法实施条例》第32条
  5. 有依法缴纳税收和社会保障资金的良好记录；
  6. 参加本次采购活动前三年内，在经营活动中没有重大违法记录；

系统标注

此处资质要求疑似过高，建议调整为"信息系统集成二级资质"

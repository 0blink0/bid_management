# RAG系统测试指标体系（高标准版）

## 1. 分块质量指标

| 指标 | 定义 | 计算方式 | 目标值 | 备注 |
|:---|:---|:---|:---:|:---|
| **语义完整率** | 块内语义未被打断的比例 | LLM评估 + 人工抽检 | >95% | 当前chunk不出现句子被腰斩 |
| **覆盖完整率** | 分块后内容完整保留的比例 | (分块还原字数 / 原文字数) | >99% | 允许标题/页眉等小量丢失 |
| **边界准确率** | 分块边界正确的比例 | 边界在段落/句子结束处的比例 | >92% | 硬切比例 <8% |
| **块长度达标率** | 块长度在合理范围内的比例 | 300-1000字符的块占比 | >90% | 过短/过长都要扣分 |
| **元数据完整率** | 章节标题/页码等元数据齐全比例 | 有完整元数据的块 / 总块数 | >95% | 影响检索可解释性 |
| **表格保持率** | 表格结构完整保留的比例 | 完整表格块 / 原表格数 | >98% | 表格拆分不超过2行/块 |
| **重叠合理率** | 重叠率在10-20%范围内的比例 | 符合重叠率的块 / 总块数 | >85% | 过低遗漏，过高冗余 |

## 2. 检索效果指标

| 指标 | 定义 | 计算方式 | 目标值 | 难度分级 |
|:---|:---|:---|:---:|:---|
| **Recall@3** | Top3召回率 | 相关块在Top3比例 | >90% | 核心指标 |
| **Recall@5** | Top5召回率 | 相关块在Top5比例 | >95% | |
| **MRR** | 首个相关结果排名的倒数 | avg(1/rank) | >0.75 | |
| **NDCG@5** | 归一化折扣收益 | NDCG@5得分 | >0.85 | |
| **SRR** | 场景召回率(同章节) | 同章节相关块被召回 | >92% | 同章节问题 |
| **Query-Diversity** | 混合检索对不同类型Query的适应性 | 各类Query的recall波动 | <15% | 波动小=适应性强 |

## 3. 答案质量指标（LLM评估）

| 指标 | 定义 | 计算方式 | 目标值 | 评分标准 |
|:---|:---|:---|:---:|:---|
| **答案正确率** | 答案与标准答案语义等价 | GPT-4/LLM-as-Judge | >90% | 完全正确/部分正确/错误 |
| **引用召回率** | 答案引用了所有必需片段 | 必需引用被召回 / 总必需 | >95% | 关键指标 |
| **引用精确率** | 答案只引用了相关内容 | 引用全部相关 / 总引用数 | >90% | 无无关引用 |
| **幻觉率** | 答案中原文无的内容比例 | LLM自检 | <5% | 零容忍关键事实 |
| **拒答准确率** | 正确识别无法回答的问题 | 正确拒答 / 应拒答总数 | >80% | 避免乱答 |
| **立场一致性** | 多轮对话立场不矛盾 | 前后矛盾率 | <5% | |
| **结构化程度** | 答案结构化程度(列点/分节) | 结构化评分 | >85% | 便于阅读 |
